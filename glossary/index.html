VPN

Основы

Виртуальная частная сеть — зашифрованный туннель между устройством и сервером.

IP-адрес

Основы

Уникальный числовой идентификатор устройства в сети интернет.

Шифрование

Основы

Преобразование данных в нечитаемый вид без ключа расшифровки.

Туннель

Основы

Защищённый канал передачи данных через публичную сеть.

Прокси

Основы

Промежуточный сервер, перенаправляющий запросы без полного шифрования устройства.

Tor

Основы

Анонимная сеть с многослойным шифрованием через цепочку узлов.

OpenVPN

Протоколы

Открытый VPN-протокол с гибкой настройкой UDP/TCP.

WireGuard

Протоколы

Современный быстрый VPN-протокол с минимальным кодом.

IKEv2

Протоколы

Протокол IPsec для быстрого переподключения на мобильных.

L2TP

Протоколы

Устаревающий протокол туннелирования, часто с IPsec.

AES-256

Протоколы

Стандарт симметричного шифрования с ключом 256 бит.

Kill Switch

Безопасность

Блокировка интернета при обрыве VPN-соединения.

DNS

Безопасность

Система преобразования доменных имён в IP-адреса.

DNS leak

Безопасность

Утечка DNS-запросов мимо VPN-туннеля.

IP leak

Безопасность

Раскрытие реального IP-адреса при использовании VPN.

WebRTC leak

Безопасность

Утечка IP через браузерный протокол WebRTC.

No-log

Безопасность

Политика несохранения логов активности пользователей.

DPI

Цензура

GFW

Цензура

Геоблокировка

Split tunneling

Shared IP

Настройка

Один IP-адрес для многих пользователей VPN.

Dedicated IP

Настройка

Персональный IP-адрес только для вас.

Handshake

Протоколы

Процесс установления зашифрованного соединения.

PFS
